Measures of central tendency and outliers

The mean is sensitive to extreme values; the median and the mode are not.

a <- c(5, 6, 6, 7, 7, 7, 8, 8, 9, 10)
b <- c(5, 6, 6, 7, 7, 7, 8, 8, 9, 20)   # same data, one extreme value

tibble(
  dataset = c("Without outlier", "With outlier (20)"),
  mean    = c(mean(a), mean(b)),
  median  = c(median(a), median(b)),
  mode    = c(mfv(a), mfv(b))
) |> kable()
dataset mean median mode
Without outlier 7.3 7 7
With outlier (20) 8.3 7 7

Changing a single value from 10 to 20 moves the mean from 7.3 to 8.3, while the median and the mode stay the same.

Missing-value codes

The dataset does not use empty cells for missing data. It uses codes instead: 999 in the quantitative traits and 9 in the qualitative ones. If they are not replaced, R treats them as real values and every mean and plot is wrong.

quantitative <- c("fruit_diameter_mm", "weight_100_seeds_g", "flowers_per_axil",
                  "weight_10_fruits_g", "plant_height_cm", "fruit_length_mm")
qualitative  <- c("corolla_color", "fruit_epidermis", "fruit_shape",
                  "flower_position", "corolla_shape")

# Maximum value of each quantitative trait before cleaning
chili |> summarise(across(all_of(quantitative), max)) |> kable()
fruit_diameter_mm weight_100_seeds_g flowers_per_axil weight_10_fruits_g plant_height_cm fruit_length_mm
999 999 2.666667 999 999 999 
chili <- chili |>
  mutate(
    across(all_of(quantitative), ~ na_if(.x, 999)),
    across(all_of(qualitative),  ~ factor(na_if(.x, 9)))
  )

# Missing values per variable after recoding
chili |>
  summarise(across(everything(), ~ sum(is.na(.x)))) |>
  pivot_longer(everything(), names_to = "variable", values_to = "missing") |>
  filter(missing > 0) |>

Key takeaways

  • Missing-value codes such as 999 and 9 must be replaced with NA before any calculation; otherwise a single code can distort means, correlations and plots.
  • In the chili collection, only 10 of 39 accessions are complete, so analyses use the data available for each variable.
  • In the Orange data, age and trunk circumference are strongly correlated (r = 0.91), but the trees grow at different rates, and the differences between them widen with age.
